# Security Policy

## Supported version

Security fixes are applied to the latest release on the default branch.

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub's private security advisory feature for
this repository and include affected versions, impact, reproduction steps, and a minimal defensive proof.
Allow maintainers reasonable time to investigate before public disclosure.

## Scope and safe research

VulnScannerLite is intended only for systems you own or have explicit permission to assess. The project does
not authorize testing a third party. Its findings are observations and may be false positives; they are not
proof that a vulnerability is exploitable.

Reports about an unrelated target, requests for exploit development, or issues caused solely by unsafe use are
outside this project's security-reporting scope.
